プライバシーポリシー

サイトは何も収集しません。ボットは査定結果の提供と照合に必要な最小限の情報だけを保存し、/delete ですべて消去できます。

最終更新日：2026年9月30日

要点

  • サイトはCookie を使用せず、計算ツールはすべてブラウザ内で動作します。
  • ボットはスクリーンショットを保存しません。AI 解析の間だけメモリ上に置き、その後破棄します。
  • Telegram ID は元に戻せない SHA-256 ハッシュとしてのみ保存します。
  • ボットに /delete を送ると、データがすぐに消去されます。

このサイトについて

gameaccountvalue.com は Cookie を使用せず、アクセス解析・トラッキングピクセル・広告を一切使わず、第三者のスクリプト・フォント・画像を読み込みません。すべてこのドメインから配信され、Content-Security-Policy がほかの配信元をブロックします。計算ツールはブラウザ内で動作し、動かしたり選んだりした内容はどこにも送信されません。ホスティング事業者（GitHub Pages）は、一般的なホスティングと同様に、サイトを表示するために IP アドレスなどの技術的なリクエスト情報を処理しますが、私たちがその情報を受け取ったり保存したりすることはありません。マーケットプレイス、パブリッシャー、Twitch などへのリンク先は各社のサイトであり、それぞれのプライバシーポリシーが適用されます。

本サイトは Cloudflare（コンテンツ配信・セキュリティネットワーク）経由でも配信されており、ホスティング事業者と同様に IP アドレスなどの技術的なリクエストデータを処理します。私たちはそれを受け取らず、保存もしません。ブラウザはこのサイト専用の小さな設定を 2 つだけ保存し、どこにも送信しません。「アニメーションを停止」を押したかどうか（ローカルストレージ）と、今回の訪問で装飾用の携帯電話タイムラインのどの機種を最後に表示したか（セッションストレージ）です。ブラウザでサイトデータを消去すると削除されます。

スクリーンショットと AI 解析

査定を行うため、スクリーンショットは送信された時点で AI 画像解析用に Google の Gemini API へ送られます。この工程なしではサービスは動作しません。Google はこのデータを自社の API 規約とプライバシーポリシーに基づいて処理します。Google が API への入力をどれだけ保持するかは、私たちには管理できません。スクリーンショットがほかの第三者に渡ることはありません。

ボットが保存するもの

  • ハッシュ化した Telegram ID、18歳以上向け規約への同意の有無、最後に無料査定を受けた日付。
  • ゲーム名、日付、AI が生成した査定結果。
  • 有料査定の場合：カードに印字される名前（Telegram の名、またはスクリーンショットから読み取ったゲーム内の名前）、カードの番号・エディション・ランク、そして返金に対応するために保存する Telegram の支払い ID。
  • 各スクリーンショットのフィンガープリント——画像そのものではなく、画像から計算した短いコード。同じスクリーンショットが別々の人に使い回されていないかを確認するために使います。フィンガープリントは90日後に削除されます。
  • フィードバックやサポートへのメッセージなど、あなたがボットで自ら送った内容。
  • 紹介プログラムやパートナープログラムを利用している場合は、その記録。

同じスクリーンショットで AI を二度動かさないよう、AI による画像の読み取り結果は、画像ファイルの一方向ハッシュをキーとしてキャッシュされます。このキャッシュにユーザー ID は含まれず、あなたとは結び付いていません。

決して収集しないもの

  • スクリーンショット——ディスクに書き込まれることも、私たちが保持することもありません。
  • ゲームのログイン情報やパスワード。求めることは一切ありません。
  • 支払いカードの情報——決済は Telegram が行います。
  • 電話番号や連絡先。

あなたのカードと公開ページ

有料査定では、リンクで共有できるよう、ボットがカード画像と推定価格を telegra.ph（Telegram の公開サービス）のページにも掲載します。私たちがそのリンクをどこかに公開することはありませんが、リンクを知っている人は誰でもページを開けますし、検索エンジンに登録される可能性もあります。Telegraph ではページを削除できないため、/delete でも削除できません。カードには印字された名前が表示されます。名前を公開ページに載せたくない場合は、リンクを共有しないでください。また、カード番号や Scan ID を知っている人は、ボットでカードを照合でき、カードに印字された内容が表示されます。

公開ランキング（任意）。 有料査定のあと、ボットはあなたのカードを /top ランキングに載せるかどうかを尋ねます。選択肢は「カードに印字された名前で掲載」「カード番号のみで掲載」「掲載しない」です。掲載されるのはその名前または番号、ゲーム名、推定価値です。あなたが選ばない限り何も掲載されず、/delete を使うと他のデータと一緒にこの掲載も削除されます。

法的根拠

上記のデータは、GDPR 第6条1項(b)に基づいて処理します。ご依頼の査定を行うために必要だからです。有料機能では、支払い状況の処理もその契約の履行に必要です。スクリーンショットのフィンガープリントは、不正防止という私たちの正当な利益（第6条1項(f)）に基づいて処理し、保存は90日間に限ります。

保存期間

データは、あなたが /delete で削除するまで保存されます。このコマンドを使うと、ハッシュ化した ID に紐づくもの——査定結果、カード、支払いの参照情報、フィンガープリント、メッセージ、紹介・パートナー残高——がすぐにすべて削除されます。削除後はカードの照合ができなくなります。スクリーンショットのフィンガープリントは、いずれにしても90日後に自動で削除されます。上記の Telegraph 公開ページは、私たちの管理外です。

自動化された意思決定

査定はすべて AI による自動処理で行われ、個々の結果を人が確認・承認することはありません。この査定があなたに法的な効果や同程度に重大な影響を与えることはありません。情報提供と娯楽のための推定であり、拘束力のある価格、与信判断、資格審査ではないため、GDPR 第22条は適用されません。結果の読み方については、利用規約の AI に関する注意事項をご覧ください。

あなたの権利

お住まいの地域によっては、データへのアクセス、訂正、削除、処理の制限、処理への異議、コピーの受け取りを求める権利があります。私たちが保存する情報はごくわずかなため、ほとんどの権利は同じ方法で行使できます。ボットでご連絡いただくか、/delete をお使いください。EU・EEA・英国にお住まいの方は、いつでも現地のデータ保護監督機関に苦情を申し立てることもできます。
