นโยบายความเป็นส่วนตัว

เว็บไซต์ไม่เก็บข้อมูลใด ๆ บอทเก็บเฉพาะข้อมูลขั้นต่ำที่จำเป็นในการส่งและตรวจสอบผลประเมินของคุณ และ /delete จะลบทั้งหมด

อัปเดตล่าสุด: 30 กันยายน 2026

สรุปสั้น ๆ

  • เว็บไซต์ไม่ใช้คุกกี้ และเครื่องคำนวณทำงานในเบราว์เซอร์ของคุณทั้งหมด
  • บอทไม่เคยเก็บภาพหน้าจอของคุณ ภาพจะอยู่ในหน่วยความจำระหว่างที่ AI วิเคราะห์เท่านั้น แล้วถูกลบทิ้ง
  • Telegram ID ของคุณถูกเก็บในรูปแบบแฮช SHA-256 ทางเดียวเท่านั้น
  • ส่ง /delete ในบอทเพื่อลบข้อมูลของคุณทันที

เว็บไซต์นี้

gameaccountvalue.com ไม่ใช้คุกกี้ ไม่ใช้เครื่องมือวิเคราะห์ พิกเซลติดตาม หรือโฆษณา และไม่โหลดสคริปต์ ฟอนต์ หรือรูปภาพจากบุคคลที่สาม ทุกอย่างมาจากโดเมนนี้ และ Content-Security-Policy จะบล็อกแหล่งอื่น เครื่องคำนวณทำงานในเบราว์เซอร์ของคุณ สิ่งที่คุณเลื่อนหรือเลือกจะไม่ถูกส่งไปที่ใดเลย ผู้ให้บริการโฮสต์ (GitHub Pages) ประมวลผลข้อมูลคำขอทางเทคนิคทั่วไป เช่น ที่อยู่ IP เพื่อแสดงเว็บไซต์ เหมือนผู้ให้บริการโฮสต์ทั่วไป เราไม่ได้รับและไม่ได้เก็บข้อมูลนั้น ลิงก์ไปยังตลาดซื้อขาย ผู้จัดจำหน่ายเกม Twitch และแหล่งอื่น ๆ จะเปิดเว็บไซต์ของพวกเขาเอง ซึ่งมีนโยบายความเป็นส่วนตัวของตนเอง

ภาพหน้าจอและการวิเคราะห์ด้วย AI

เพื่อประเมินมูลค่า ภาพหน้าจอของคุณจะถูกส่งไปยัง Gemini API ของ Google เพื่อวิเคราะห์ภาพด้วย AI ในตอนที่คุณส่ง บริการจะทำงานไม่ได้หากไม่มีขั้นตอนนี้ Google ประมวลผลข้อมูลนี้ตามข้อกำหนด API และนโยบายความเป็นส่วนตัวของ Google เอง เราไม่สามารถควบคุมระยะเวลาที่ Google เก็บข้อมูลที่ส่งเข้า API ได้ ไม่มีบุคคลที่สามรายอื่นได้รับภาพหน้าจอของคุณ

ข้อมูลที่บอทเก็บไว้

  • Telegram ID ของคุณในรูปแบบแฮชทางเดียว ข้อมูลว่าคุณยอมรับเงื่อนไขสำหรับผู้มีอายุ 18 ปีขึ้นไปแล้วหรือยัง และวันที่คุณได้รับการประเมินฟรีครั้งล่าสุด
  • เกม วันที่ และผลการประเมินที่ AI สร้างขึ้น
  • สำหรับการตรวจสอบแบบชำระเงิน: ชื่อที่พิมพ์บนการ์ดของคุณ (ชื่อใน Telegram หรือชื่อในเกมที่อ่านได้จากภาพหน้าจอ) หมายเลข รุ่น และระดับของการ์ด รวมถึงรหัสการชำระเงิน Telegram ที่เก็บไว้เพื่อให้คืนเงินได้
  • ลายนิ้วมือของภาพหน้าจอแต่ละภาพ — รหัสสั้น ๆ ที่คำนวณจากภาพ ไม่ใช่ตัวภาพ — ใช้สังเกตว่ามีคนหลายคนนำภาพเดียวกันมาใช้ซ้ำหรือไม่ ลายนิ้วมือจะถูกลบหลังจาก 90 วัน
  • สิ่งที่คุณเลือกเขียนถึงเราในบอท เช่น ความคิดเห็นหรือข้อความถึงฝ่ายสนับสนุน
  • ข้อมูลโปรแกรมแนะนำเพื่อนและโปรแกรมพาร์ตเนอร์ หากคุณใช้งาน

เพื่อไม่ต้องรัน AI ซ้ำกับภาพหน้าจอชุดเดิม ผลการอ่านภาพของ AI จะถูกแคชไว้ภายใต้แฮชทางเดียวของไฟล์ภาพ แคชนี้ไม่มี ID ผู้ใช้และไม่เชื่อมโยงกับคุณ

สิ่งที่เราไม่เคยเก็บ

  • ภาพหน้าจอของคุณ — ไม่เคยถูกเขียนลงดิสก์หรือเก็บไว้โดยเรา
  • ข้อมูลล็อกอินหรือรหัสผ่านเกม เราไม่เคยขอ
  • ข้อมูลบัตรชำระเงิน — การชำระเงินดำเนินการโดย Telegram
  • หมายเลขโทรศัพท์หรือรายชื่อผู้ติดต่อของคุณ

การ์ดของคุณและหน้าสาธารณะของการ์ด

สำหรับการตรวจสอบแบบชำระเงิน บอทจะเผยแพร่ภาพการ์ดและมูลค่าประเมินของคุณบนหน้าเว็บที่ telegra.ph (บริการเผยแพร่ของ Telegram) ด้วย เพื่อให้คุณแชร์ด้วยลิงก์ได้ เราไม่ได้เผยแพร่ลิงก์นั้นที่ใด แต่ใครก็ตามที่มีลิงก์สามารถเปิดหน้านั้นได้ และเครื่องมือค้นหาอาจจัดทำดัชนีหน้านั้น Telegraph ไม่อนุญาตให้ลบหน้า ดังนั้น /delete จึงลบหน้านี้ไม่ได้ การ์ดจะแสดงชื่อที่พิมพ์อยู่ หากคุณไม่ต้องการให้ชื่อของคุณปรากฏบนหน้าสาธารณะ อย่าแชร์ลิงก์ นอกจากนี้ ใครก็ตามที่รู้หมายเลขการ์ดหรือ Scan ID ของคุณสามารถตรวจสอบการ์ดในบอทได้ ซึ่งจะแสดงข้อมูลที่พิมพ์อยู่บนการ์ด

ฐานทางกฎหมาย

เราประมวลผลข้อมูลข้างต้นตามมาตรา 6(1)(b) ของ GDPR เพราะจำเป็นต่อการประเมินที่คุณร้องขอ สำหรับฟีเจอร์แบบชำระเงิน การประมวลผลสถานะการชำระเงินก็จำเป็นต่อสัญญานั้นด้วย ลายนิ้วมือของภาพหน้าจอประมวลผลตามมาตรา 6(1)(f) ซึ่งเป็นประโยชน์โดยชอบธรรมของเราในการป้องกันการฉ้อโกง และจำกัดไว้ที่ 90 วัน

ระยะเวลาการเก็บรักษา

ข้อมูลจะถูกเก็บไว้จนกว่าคุณจะลบเองด้วย /delete คำสั่งนี้จะลบทุกอย่างที่เชื่อมโยงกับ ID ที่แฮชแล้วของคุณทันที ได้แก่ ผลประเมิน การ์ด ข้อมูลอ้างอิงการชำระเงิน ลายนิ้วมือ ข้อความ และยอดคงเหลือจากโปรแกรมแนะนำเพื่อนหรือพาร์ตเนอร์ หลังจากลบแล้ว การ์ดของคุณจะตรวจสอบไม่ผ่านอีก ไม่ว่าอย่างไร ลายนิ้วมือของภาพหน้าจอจะถูกลบอัตโนมัติหลังจาก 90 วัน หน้าสาธารณะบน Telegraph ที่กล่าวถึงข้างต้นอยู่นอกการควบคุมของเรา

การตัดสินใจโดยอัตโนมัติ

ผลประเมินของคุณสร้างขึ้นทั้งหมดด้วยการประมวลผล AI อัตโนมัติ ไม่มีบุคคลใดตรวจสอบหรืออนุมัติผลแต่ละรายการ ผลนี้ไม่มีผลทางกฎหมายหรือผลกระทบสำคัญในลักษณะเดียวกันต่อคุณ เป็นเพียงการประเมินเพื่อข้อมูลและความบันเทิง ไม่ใช่ราคาที่มีผลผูกพัน การตัดสินใจด้านสินเชื่อ หรือการตรวจสอบคุณสมบัติ มาตรา 22 ของ GDPR จึงไม่มีผลบังคับใช้ ดูคำเตือนเกี่ยวกับ AI ในข้อกำหนดการให้บริการของเราเพื่อทำความเข้าใจผลลัพธ์

สิทธิของคุณ

ขึ้นอยู่กับที่ที่คุณอาศัยอยู่ คุณอาจมีสิทธิเข้าถึง แก้ไข ลบ จำกัด หรือคัดค้านการประมวลผลข้อมูลของคุณ และขอรับสำเนาข้อมูล เนื่องจากเราเก็บข้อมูลน้อยมาก สิทธิส่วนใหญ่จึงใช้ได้ด้วยวิธีเดียวกัน คือเขียนถึงเราในบอทหรือใช้ /delete หากคุณอยู่ในสหภาพยุโรป EEA หรือสหราชอาณาจักร คุณสามารถร้องเรียนต่อหน่วยงานคุ้มครองข้อมูลในท้องถิ่นได้ทุกเมื่อ
