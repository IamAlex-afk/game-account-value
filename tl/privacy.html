Patakaran sa Privacy

Walang kinokolektang anuman ang website. Ang bot ay nagtatago lang ng pinakakaunting kailangan para maibigay at ma-verify ang iyong valuation, at binubura lahat ito ng /delete.

Huling na-update: 30 Setyembre 2026

Sa madaling salita

  • Walang cookie ang website at buong tumatakbo ang calculator sa iyong browser.
  • Hindi kailanman itinatago ng bot ang iyong mga screenshot: nasa memory lang sila habang sinusuri ng AI, saka itinatapon.
  • Ang iyong Telegram ID ay itinatago lang bilang one-way SHA-256 hash.
  • Ipadala ang /delete sa bot para agad mabura ang iyong data.

Ang website na ito

Ang gameaccountvalue.com ay walang cookie, walang analytics, tracking pixel o advertising, at hindi naglo-load ng script, font o larawan mula sa ibang partido. Lahat ay galing sa domain na ito, at hinaharangan ng Content-Security-Policy ang ibang pinagmulan. Tumatakbo ang calculator sa iyong browser: walang ipinapadala kahit saan sa anumang iyong ginagalaw o pinipili. Ang hosting provider (GitHub Pages) ay nagpoproseso ng karaniwang teknikal na data ng request, gaya ng IP address, para maipakita ang site — tulad ng anumang web host; hindi namin ito natatanggap o itinatago. Ang mga link papunta sa marketplace, publisher, Twitch at iba pang source ay nagbubukas ng sarili nilang site, na may sariling patakaran sa privacy.

Mga screenshot at pagsusuri ng AI

Para makagawa ng valuation, ipinapadala ang iyong mga screenshot sa Gemini API ng Google para sa AI image analysis sa sandaling ipasa mo ang mga ito. Hindi gagana ang serbisyo nang wala ang hakbang na ito. Pinoproseso ng Google ang data na ito ayon sa sarili nitong API terms at patakaran sa privacy; hindi namin kontrolado kung gaano katagal itinatago ng Google ang mga API input. Walang ibang third party na nakakatanggap ng iyong mga screenshot.

Ano ang itinatago ng bot

  • Ang iyong Telegram ID bilang one-way hash, kung tinanggap mo na ang 18+ na mga tuntunin, at ang petsa ng huli mong libreng estimate.
  • Ang laro, ang petsa at ang resulta ng valuation na gawa ng AI.
  • Para sa bayad na audit: ang pangalang naka-print sa iyong card (ang first name mo sa Telegram, o ang in-game name na nabasa sa iyong mga screenshot), ang numero, edition at tier ng card, at ang Telegram payment charge ID, na itinatago para ma-refund ang bayad kung kailangan.
  • Isang fingerprint ng bawat screenshot — maikling code na kinalkula mula sa larawan, hindi ang larawan mismo — para mapansin kung iisang screenshot ang ginagamit ulit ng iba’t ibang tao. Binubura ang mga fingerprint pagkalipas ng 90 araw.
  • Anumang pinili mong isulat sa amin sa bot, gaya ng feedback o mensahe sa support.
  • Mga record ng referral at partner program, kung ginagamit mo ang mga ito.

Para hindi dalawang beses patakbuhin ang AI sa magkaparehong screenshot, naka-cache ang pagbasa nito sa mga larawan sa ilalim ng one-way hash ng mga image file. Walang user ID ang cache at hindi ito naka-link sa iyo.

Ang hindi namin kailanman kinokolekta

  • Ang iyong mga screenshot — hindi kailanman isinusulat sa disk o itinatago namin.
  • Mga login o password ng laro. Hindi namin kailanman hinihingi ang mga ito.
  • Detalye ng payment card — ang Telegram ang humahawak ng bayad.
  • Ang iyong numero ng telepono o mga contact.

Ang iyong card at ang pampublikong page nito

Sa bayad na audit, inilalathala rin ng bot ang larawan ng iyong card at ang tinantyang halaga sa isang page sa telegra.ph (ang publishing service ng Telegram), para maibahagi mo ito gamit ang link. Hindi namin inilalathala ang link na iyon kahit saan, pero sinumang may hawak nito ay makakapagbukas ng page, at maaari itong i-index ng mga search engine. Hindi pinapayagan ng Telegraph na burahin ang mga page, kaya hindi ito maaalis ng /delete. Makikita sa card ang pangalang naka-print dito — kung ayaw mong nasa pampublikong page ang pangalan mo, huwag ibahagi ang link. Bukod dito, sinumang nakakaalam ng numero ng iyong card o Scan ID ay puwedeng mag-check ng card sa bot, na nagpapakita ng data na naka-print dito.

Legal na batayan

Pinoproseso namin ang data sa itaas ayon sa GDPR Art. 6(1)(b): kailangan ito para magawa ang valuation na hiniling mo. Para sa mga bayad na feature, kailangan din ang pagproseso ng status ng iyong bayad para sa kontratang iyon. Ang mga screenshot fingerprint ay pinoproseso ayon sa Art. 6(1)(f), ang lehitimong interes naming pigilan ang panloloko, at limitado sa 90 araw.

Gaano katagal namin itinatago

Itinatago ang data hanggang ikaw mismo ang magbura nito gamit ang /delete. Agad na inaalis ng command na iyon ang lahat ng naka-link sa iyong hashed ID: valuation, card, payment reference, fingerprint, mensahe, at referral o partner balance. Kapag nabura na, hindi na mave-verify ang iyong card. Sa anumang kaso, awtomatikong nabubura ang mga screenshot fingerprint pagkalipas ng 90 araw. Wala sa aming kontrol ang pampublikong Telegraph page na inilarawan sa itaas.

Awtomatikong pagpapasya

Buong ginagawa ng awtomatikong pagproseso ng AI ang iyong valuation — walang taong nagrerepaso o nag-aapruba ng bawat resulta. Wala itong legal o katulad na mabigat na epekto sa iyo: isa itong tantya para sa impormasyon at libangan, hindi isang presyong may bisa, desisyon sa credit, o pagsusuri ng eligibility, kaya hindi saklaw ng GDPR Art. 22. Basahin ang AI disclaimer sa aming Mga Tuntunin ng Serbisyo para malaman kung paano unawain ang resulta.

Ang iyong mga karapatan

Depende sa kung saan ka nakatira, maaaring may karapatan kang i-access, itama, burahin, limitahan o tutulan ang pagproseso ng iyong data, at makatanggap ng kopya nito. Dahil napakaunti ng itinatago namin, halos lahat ng karapatang ito ay ginagamit sa parehong paraan: sumulat sa amin sa bot o gamitin ang /delete. Kung nasa EU, EEA o UK ka, maaari ka ring magreklamo anumang oras sa lokal na awtoridad sa proteksyon ng data.
