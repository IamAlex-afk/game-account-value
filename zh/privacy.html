隐私政策

网站不收集任何信息。机器人只保存交付和验证估值所需的最少信息，发送 /delete 即可全部删除。

最后更新：2026年9月30日

简要说明

  • 网站不使用 Cookie，计算器完全在你的浏览器中运行。
  • 机器人从不保存你的截图：截图只在 AI 分析期间存放于内存中，随后即被丢弃。
  • 你的 Telegram ID 只以不可逆的 SHA-256 哈希值形式保存。
  • 在机器人中发送 /delete，即可立即删除你的数据。

本网站

gameaccountvalue.com 不使用 Cookie，不使用任何统计分析、追踪像素或广告，也不加载任何第三方脚本、字体或图片。所有内容都来自本域名，内容安全策略（Content-Security-Policy）会阻止其他来源。计算器在你的浏览器中运行：你拖动或选择的任何内容都不会被发送到任何地方。托管服务商（GitHub Pages）与其他托管服务一样，为展示网站会处理 IP 地址等常规技术请求数据；我们不会接收或保存这些数据。指向交易平台、发行商、Twitch 等来源的链接会打开它们自己的网站，适用其各自的隐私政策。

截图与 AI 分析

为了生成估值，你的截图会在提交时发送到 Google 的 Gemini API 进行 AI 图像分析。没有这一步，服务就无法运行。Google 依据其自身的 API 条款和隐私政策处理这些数据；Google 保留 API 输入数据多久，我们无法控制。除此之外，没有任何其他第三方会收到你的截图。

机器人保存的信息

  • 哈希处理后的 Telegram ID、你是否已同意 18 岁以上使用条款，以及你最近一次免费估算的日期。
  • 游戏、日期以及 AI 生成的估值结果。
  • 付费评估：印在卡牌上的名字（你的 Telegram 名字，或从截图中识别出的游戏内昵称）、卡牌编号、版本和等级，以及为便于退款而保存的 Telegram 支付 ID。
  • 每张截图的指纹——根据图片计算出的一段短代码，而非图片本身——用于发现同一张截图被不同的人重复使用。指纹会在 90 天后删除。
  • 你主动在机器人中写给我们的内容，例如反馈或客服消息。
  • 如果你参与推荐计划或合作伙伴计划，相关记录。

为避免对相同截图重复运行 AI，AI 对图片的识别结果会以图片文件的不可逆哈希为键进行缓存。该缓存不含任何用户 ID，也不与你关联。

我们绝不收集的信息

  • 你的截图——绝不会写入磁盘，也不会由我们保存。
  • 游戏账号或密码。我们从不索要。
  • 支付卡信息——支付由 Telegram 处理。
  • 你的手机号码或通讯录。

你的卡牌及其公开页面

付费评估时，机器人还会把你的卡牌图片和估算价值发布到 telegra.ph（Telegram 的发布服务）上的一个页面，方便你通过链接分享。我们不会在任何地方公开这个链接，但任何拿到链接的人都能打开页面，搜索引擎也可能将其收录。Telegraph 不允许删除页面，因此 /delete 无法删除它。卡牌上会显示印在上面的名字——如果你不希望名字出现在公开页面上，请不要分享链接。此外，知道你的卡牌编号或 Scan ID 的人都可以在机器人中查验这张卡，机器人会显示卡上印的信息。

法律依据

我们依据 GDPR 第 6 条第 1 款 (b) 项处理上述数据：这是完成你所请求估值的必要条件。对于付费功能，处理你的支付状态也是履行该合同所必需的。截图指纹依据第 6 条第 1 款 (f) 项——即我们防范欺诈的正当利益——进行处理，且保存期不超过 90 天。

保存期限

数据会一直保存，直到你自己用 /delete 删除。该命令会立即删除与你的哈希 ID 相关的全部内容：估值、卡牌、支付记录引用、指纹、消息，以及推荐或合作伙伴余额。删除后，你的卡牌将无法再通过验证。无论如何，截图指纹都会在 90 天后自动删除。上文所述的 Telegraph 公开页面不在我们的控制范围内。

自动化决策

你的估值完全由 AI 自动处理生成——没有人审核或批准单个结果。它不会对你产生法律效力或同等重大的影响：它只是用于参考和娱乐的估算，而不是有约束力的价格、信用决定或资格审查，因此不适用 GDPR 第 22 条。如何理解结果，请参阅我们服务条款中的 AI 免责声明。

你的权利

根据你所在地区，你可能有权访问、更正、删除你的数据，限制或反对对数据的处理，并获取数据副本。由于我们保存的信息极少，大多数权利都可以用同一种方式行使：在机器人中联系我们，或使用 /delete。如果你身处欧盟、欧洲经济区或英国，也可以随时向当地数据保护监管机构投诉。
